Experimente o preenchimento de um registro mensal de resíduos.

Formulário demonstrativo: os campos podem ser preenchidos, mas os dados não são enviados nem salvos. O total não é calculado automaticamente.

02. Peso dos resíduos

Informe o peso em quilogramas. Use zero quando não houver registro na semana.

Sobre o registro

Uma unidade, um período.

  1. Escolha a unidade correspondente.
  2. Informe o mês de referência.
  3. Distribua o peso entre as semanas.
  4. Utilize a quinta semana somente quando necessário.

A estrutura mantém os cinco campos semanais do projeto original.
